# Stimma 1.0.16: day-zero FLUX.3 Klein support

Thank you to everyone trying Stimma and sharing feedback. This release adds FLUX.3 Klein workflows in ComfyUI-Stimma and matching prompt enhancement in the app. We’ve also redesigned sharing, made creation history easier to follow, and added a choice of where to save your exports.

## FLUX.3 Klein in ComfyUI-Stimma

Generate from a prompt, or add an image to edit it. You can use the tool directly or ask the agent to run it. It accepts up to ten images in total: the first is the image to edit, and the others provide references.

- **Generate and edit:** both Klein and the undistilled Klein Base are available, with optional LoRAs and advanced sampling controls.
- **Remove, Repaint, and Expand:** dedicated inpaint and outpaint tools work with Stimma’s image editor. Inpainting preserves pixels outside the mask; outpainting preserves the original image while filling the added canvas.
- **Keep edits aligned:** single-image edits retain the input’s dimensions within the supported size limits, up to 4 MP and 4096 pixels per side. Larger images are resized to fit. Multi-image edits use a smaller reference budget and follow the prepared first image.
- **Preserve unchanged areas:** enabled by default, this option restores original pixels outside the detected edit region. It steps aside for whole-image changes such as restyling.
- **Prompt enhancement for FLUX.3:** Stimma recognizes Klein as its own model family. Enhancement uses detailed captions for generation and edit instructions that refer to images by their order, including when the agent runs the tool. Prompt enhancement requires a configured chat model.

### Getting started with ComfyUI

Update **both Stimma and ComfyUI-Stimma**, then restart ComfyUI. Use **ComfyUI 0.41.0 or later**; updating the connector does not update ComfyUI itself. Accept access to the [FLUX.3 Klein model files on Hugging Face](https://huggingface.co/black-forest-labs/flux-3-image-klein-comfy), then provide a Hugging Face token in the provider manager to download the required files. The desktop update supplies model recognition and prompt enhancement; the connector supplies the workflows.

### Using Stimma Account Credits

FLUX.3 Klein is also available using Stimma Account Credits.

## Share more kinds of work

The redesigned **Share link** dialog previews what you’re publishing and makes upload progress and sharing status clearer. Shared pages support images, video, audio, documents, vectors, sprites, packages, sets, grids, and layouts, with viewers suited to each type.

- Choose **Include how it was made** to publish creation details, and review those details before sharing.
- Find, copy, open, or delete your published links in **Settings → Shared links**.
- Shared sprites play their animations, audio has playback with a waveform, and packages include their guide and downloadable files.
- Creation history uses the same presentation in the app and on shared pages, making prompts, inputs, and editing steps easier to follow.

## Export where you want

On desktop, choose a destination when exporting. Stimma remembers the last export folder for your profile. Export several items as individual files, or combine them into a ZIP; **Save to Downloads** remains available for a quick save.

Chat file attachments, saved artifacts, and archive previews have consistent download controls. Fixed downloads that did nothing in the desktop app. **Use these settings** in the Info panel now correctly opens the tool with the item’s generation settings.

## More model choices

- **Qwen Image 2.1 Turbo in ComfyUI-Stimma:** generate and edit with reference images, optional transparent output, and an eight-step default. Install its separate model checkpoint through the provider manager.
- **Qwen Image 2.1 Pro and Turbo using Stimma Account Credits:** additional hosted generation and editing choices, with up to ten input images.
- Updated chat catalogs include **Claude Opus 5.5, GPT-6.1 Sol, and GPT-6 Luna**. Saved model preferences carry forward when supported by the replacement model.

## Fixes

- Fixed ComfyUI status loading and model-download disk checks on Windows.
- Correctly detect the ComfyUI-Manager included with ComfyUI Desktop, avoiding false missing-manager messages.
- Keep the app responsive while the agent runs Python work.
