## Stimma 1.0.14 is out

Thank you for the bug reports, ideas, and feedback. This is a big release for Stimma's foundations, with some new ways to put them to work.

**[Your library, across computers.](https://docs.stimma.ai/remote-access/)** Leave work running at home and access that machine's library and tools from another computer. Enable **Settings → Stimma Server**, sign into the same account, and choose your server in the sidebar. Use Tailscale outside your LAN.

**Headless Linux servers.** Run Stimma Server in Docker on amd64 or arm64, without a desktop. Connect from the desktop app, mount existing media folders as Sources, and schedule updates around active work.

**Use your ChatGPT or Codex subscription.** Sign in with OpenAI to use your subscription's models without a separate API key.

**A faster desktop app.** The move to Electron brings more consistent rendering, faster startup (especially on Windows), and improvements to the image editor, Wacom input, and Linux Wayland dragging. Linux has had extensive testing on Omarchy and Ubuntu.

Also: **GPT 6 Astra**, **Claude Fable 5.1**, and **GLM 5.3 Flash**; smoother ComfyUI integration and a **Krea 2 RAW→Turbo** workflow; LoRA weights from **-10 to 10**; and fixes for prompt enhancement, chat cancellation, saved model selections, and slideshows.

Let us know how it goes—your feedback helps shape what comes next.
