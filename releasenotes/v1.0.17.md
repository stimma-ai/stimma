# Stimma 1.0.17: video keyframes, local voices, and more model choices

Thank you to everyone trying Stimma and sharing feedback. This release gives you more control over generated video, adds local speech and voice cloning, and expands image generation and editing both in ComfyUI and using Stimma Account Credits. New creative skills help finish videos and prepare Cricut files, alongside improvements to chat, loading, and remote connections.

## Pin images and clips on a video's timeline

Guide a video with more than its first frame. The new keyframes control lets you place still images, individual video frames, and clips at specific points on the output timeline.

- Drag references or results onto the timeline, or click a position to choose media.
- Move a pin, snap it to a frame, replace it, or remove it. For video inputs, choose a single frame or a clip and adjust where the clip starts and how much to use.
- **MiniMax H3 Reference to Video** workflows in ComfyUI support pinned stills and clips, including a clip's sound where enabled.
- **LTX 2.3 and LTX 2.5 Image to Video** workflows in ComfyUI support pinned stills and clips for visual guidance; these pins do not carry sound.

Update both Stimma and ComfyUI-Stimma, then restart ComfyUI for the new controls and workflows. Which pins and positions are available depends on the selected tool.

## Generate speech locally

Six new ComfyUI-Stimma workflows cover narration, voice design, cloning, and dialogue:

- **Qwen3-TTS Custom Voice:** choose a preset speaker and give delivery instructions.
- **Qwen3-TTS Voice Design:** describe a voice and generate a sample. Reuse a sample with Voice Clone to keep the voice consistent across jobs.
- **Qwen3-TTS Voice Clone:** supply a clean speech reference and new text; the reference is transcribed automatically.
- **Fish Audio Drama 3:** generate speech from text, with delivery cues such as whispers, laughter, and sighs.
- **Fish Audio Drama 3 Voice Clone:** use a speech reference to guide the voice for a new recording.
- **Fish Audio Drama 3 Dialogue:** provide two voice references and a script with speaker labels.

Update ComfyUI-Stimma and use the provider manager to install the required node packs and model files, then restart ComfyUI. Hardware requirements vary by model; Drama 3's FP8 setup is intended for an NVIDIA GPU with at least 8 GB VRAM and about 48 GB system RAM.

## More image tools in ComfyUI

**MOSS-Image Base and SFT** support text-to-image generation with natural-language prompts, tag sequences, and structured layout prompts. Separate Base Turbo and SFT Turbo workflows use eight-step adapters. **MOSS-Image SFT Edit** adds image editing with up to three additional reference images.

The image editor's **Repaint** picker gains **Qwen Image 2.1 Inpaint**, **Qwen Image 2.1 Turbo Inpaint**, and **MOSS-Image SFT Inpaint**. Select a region and describe its replacement. The tools use surrounding context, return the source image's dimensions, and preserve pixels outside the grown and feathered mask. Mask growth, feathering, and context are adjustable.

The provider manager can install the models and supporting nodes. MOSS requires a current ComfyUI build with native MOSS-Image support; its editing workflow also requires native MOSS image-edit support. Updating the connector does not update ComfyUI itself.

FLUX.3 Klein workflows also receive corrected sampling and revised prompt enhancement. LTX 2.5 has its own model-specific prompt enhancement in Stimma.

## More choices using Stimma Account Credits

### Video

- **MiniMax H3, H3 Fast, H3 Max, and H3 Max Turbo:** text-to-video and image-to-video, with first and last frames.
- **MiniMax H3, H3 Fast, and H3 Max Reference to Video:** image, video, and voice references.
- **LTX 2.5 Pro and Fast:** text-to-video and image-to-video, with audio and camera controls.

The timeline keyframes described above are supplied by the local ComfyUI workflows. Hosted video tools expose their own supported reference and frame controls.

### Images

- **GPT Image 2.5 Flare and Sunburst**, including multi-reference editing and transparent backgrounds.
- **FLUX 3 Image**, the full image model alongside the existing FLUX.3 Klein tools.
- **Nano Banana 2.1** and **Muse Image**, with reference editing and optional search grounding.
- **Qwen Image 3.0 and 3.0 Pro**, **Seedream 5.0 Pro and Flash**, **Grok Imagine Image 2.0**, and **Ideogram 4.5** for generation and editing.
- **MOSS Image SFT** for text-to-image generation, including structured layout prompts.

Reference limits, output sizes, quality options, and prices vary by tool. Hosted MOSS Image SFT is generation-only; the MOSS editing tools are available through ComfyUI-Stimma.

## New skills for finished work

Install or update the relevant stimpacks from the **Stimpacks** page:

- **Video Production**, in Stimma Essentials, helps plan loops, continuations, transitions, and multi-shot sequences. It includes tools for checking joins and correcting exposure differences, repeated frames, and audio transitions, with guidance for choosing and reviewing the join.
- **Stimma Cricut** prepares die-cut sticker PNGs for Print Then Cut and cut-safe SVG layers at physical size for vinyl, iron-on, stencils, and paper projects. It checks geometry and prepares files for Cricut Design Space.
- **Vector Design** can select fonts and turn text into outlines directly, including when preparing cutting-machine files.

## Steer the agent while it works

Press **Enter** to send a follow-up into the running turn. Use **Alt+Enter** to queue it for after the current turn. Pending messages can be edited and are retained through Stop; Stop also interrupts running providers more promptly.

The agent can find media from earlier in its own conversation and use face and visual-similarity tools to compare and find images. ComfyUI tools now supply clearer descriptions and usage instructions, including the roles of reference inputs.

## In development: the mobile interface

Work continues on the iOS and Android apps. This round improves the tool interface for smaller screens, with a compact drawer, focused parameter sheets, and a foldable layout. Double-tap Run to enter Forever mode, keep the screen awake during generation, and recover connections more reliably after backgrounding or switching networks.

**The mobile apps are not released and are not available in the App Store or Google Play.** Developers can build them from the [source](https://stimma.ai/source/). Your connected computer or server still runs the models and generation tools.

## Loading, playback, and fixes

- Home loads progressively, and long chats open with recent turns before loading older history as you scroll.
- Improved reconnection and update tracking when using [remote access](https://docs.stimma.ai/remote-access/), including after sleep or network changes.
- Fixed visual search making other app requests wait.
- Fixed the tool assistant restoring prompt text you had edited or cleared, and overlooking manual changes to Instructions.
- Fixed slow, repeated prompt edits in the tool assistant, especially with long prompts.
- Keep a provider's tools visible while its catalog refreshes, and open media menus without waiting for a server round trip.
- Recover saved chat progress after restarting the app.
- Video artifacts in chat use the full player and scrubber. Sets show video-frame thumbnails and support playback inside the set.
- Chat slideshows follow transcript order, including images shown more than once.
- Preserve image selections when dismissing editor menus, and dismiss the topmost overlay with Escape.
- Fixed stale thumbnails after deleting media and temporary files accumulating when dragging from remote libraries.
- Improved profile PIN enforcement for live updates and shared settings.
- Prompt-enhancement failures include clearer provider diagnostics to help with retries.
