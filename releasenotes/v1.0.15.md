# Stimma 1.0.15: MCP, Draw Things, New Skills, and Qwen Image 2.1

Thank you to everyone trying Stimma and sharing feedback. This release connects your library and tools to external assistants through MCP and adds Draw Things support on macOS. New skills help turn character artwork into animated sprites and export app icons for the projects you build, with brand kits and printable labels alongside them. Qwen Image 2.1 joins ComfyUI-Stimma, alongside improvements to everyday generation and chat.

## Connect other assistants through MCP (experimental)

External AI assistants can search your library, run generation tools, organize projects and boards, and create or revise documents, sprites, and packages. They can run a known tool directly or delegate creative work to Stimma's agent.

Named connections are configured per profile in Settings → MCP. Direct connections let an assistant reach a Stimma Server without keeping the desktop app open. Batches retain completed outputs and can retry confirmed failures. See the [MCP setup guide](https://docs.stimma.ai/mcp/); for a server on another computer, see [remote access](https://docs.stimma.ai/remote-access/).

## Draw Things on macOS

Set up Draw Things from Stimma's tool-provider settings for local generation on Apple Silicon Macs running macOS 14 or later. Models from your existing Draw Things model folder can be reused. Add models through the provider manager to make their tools available. Qwen Image 2.1 on Draw Things is ready on our side; availability awaits a compatible engine release.

## New Skills: sprites, app icons, brand kits, and labels

A skill gives Stimma's agent guidance for a particular kind of work: how to approach it, which tools to use, what to check, and how to deliver the result. Skills can also include reference material and code for repeatable operations such as preparing animation frames or exporting files at exact sizes. Related skills are installed and updated together as a **stimpack**.

The agent combines that guidance with the models, generation tools, and assets available in your setup. You describe what you want in chat; the skill helps it work through the task and handle the preparation and exports. A generation tool makes or edits the image, while a skill can carry the work through several steps around it.

This gives Stimma room to grow through new and updated stimpacks as well as app releases. You can install stimpacks in the **Stimpacks** page, and the agent can now create and edit local skills with supporting files for your own workflows.

The updated **Stimma Essentials**, **Stimma Labels**, and **Stimma Sprites** add the following:

### Sprites

The Sprite Design skill helps create animated characters and prepare their frames for use in a game. Sprites are now a dedicated asset type in Stimma, with animation playback and export controls.

- Prepare transparent frames, frame timing, and consistent placement across animations.
- Export individual frames, sprite sheets, texture atlases, and engine-specific formats, including Godot SpriteFrames.
- Assemble sprite packages with source frames, playback and placement metadata, and a visual guide.

### App icons

Turn a square SVG or raster master into icon sets for iOS, Android, macOS, Windows, Linux, and the web. Exports include platform-specific sizes and formats, Android adaptive icon layers, and web favicon files.

Device and desktop previews show the delivered icons in context. Adjust artwork size per platform and package the files with an HTML and PDF presentation.

### Brand kits

The Brand Kits skill helps explore and refine a visual identity, starting from existing artwork or a new brief. Bring together logo treatments, a color palette, typography, and useful applications such as a banner or launch graphic.

Deliver vector masters where available, raster exports, font resources, editable application files, and a visual guide in one package. Revise a chosen direction without losing the alternatives or unchanged files.

### Avery labels

Design labels for products, projects, and everyday use, then turn your artwork into printable sheets.

- Look up supported Avery stock by product code, or work from supplied custom sheet geometry.
- Repeat one design, mix designs, leave used positions blank, or prepare multiple sheets.
- Export an exact-size printable PDF, sheet previews, and an optional plain-paper alignment test.
- Adjust quantities, placement, and printer offsets without regenerating the artwork.

The included catalog covers a selection of Avery products. Print at Actual Size / 100% and check alignment with a plain-paper proof before using label stock.

## Qwen Image 2.1 in ComfyUI-Stimma

Generate and edit with one Qwen Image 2.1 tool. Start with a prompt to generate an image, or supply an image to edit it, with additional images as references. Edits follow the first image's aspect ratio.

- Model-specific prompt enhancement is available in Stimma, including when the agent runs the tool.
- Advanced controls expose steps, sampler, scheduler, seed, reference resolution, and optional LoRAs.
- CFG and negative-prompt controls are available for workflows that need them. At the default CFG of 1, the negative prompt has no effect.

Update the ComfyUI-Stimma connector and use a current ComfyUI build with Qwen Image 2.1 support. The provider manager can download the required model files.

## More generation controls

- MiniMax H3 accelerated workflows use LightX2V and Sol attention.
- Agent tool calls use the same model-aware prompt enhancement as the generation interface.
- Expanded GPT-6 Astra support in direct OpenAI and ChatGPT connections, including model-specific reasoning controls.
- The resolution picker separates shape and size, shows dimension locks more clearly, and accepts custom dimensions beyond the normal slider range where supported.
- Unavailable LoRAs are deselected before generation.

## In development: Stimma on mobile

Run Stimma at home and access your setup on the go. We're working on iOS and Android clients with the goal of bringing as much of Stimma's full feature set as possible to your phone, connected to the same models, tools, library, and projects you use at your desk. Your home computer or server does the work.

Mobile is still in development and isn't available yet. We'll share more as it gets closer to release.

## Packages and agent previews

Packages collect source artwork, exports, supporting files, and a custom visual guide into a reusable library asset.

- Open packages directly in Stimma and browse their files.
- Download a complete ZIP or the guide as a PDF.
- Reopen a package to replace selected artwork or files and save a new revision while preserving unrelated outputs.
- Preview agent-created files beside the chat, including live previews of work in progress.
- Answer agent questions using visual choices and copy chat code blocks with one click.

## Search, fixes, and performance

- Search asset titles, filenames, prompts, and media-type terms, with results grouped by type.
- Video grids show video frames in their thumbnails.
- Chat drafts and attachments survive navigation.
- Long chats stay more responsive while typing and streaming.

- Chat slideshows stay current and preserve batch image order.
- Fixed project-specific asset filter counts.

- Improved connection recovery and cleared stale server presence.
