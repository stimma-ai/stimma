# Release Notes

It's been a few weeks since the last release. Thank you to everyone who has tried Stimma, reported bugs, and shared feedback—it continues to shape what we work on.

1.0.14 is a big step forward for Stimma's foundations. A faster, more consistent desktop app, remote access to your library, and a headless Linux server make it easier to use Stimma across computers and keep work running at home. There are new model connections, ComfyUI improvements, and plenty of fixes alongside that work.

## Access Your Stimma Library on Any Computer

One Stimma installation can now serve its library and tools to other signed-in installations. Enable it in **Settings → Stimma Server** and it will appear automatically on other computers logged into the same Stimma account.

The server picker in the sidebar lets you move between installations. Leave Stimma running at home to generate media, produce grids or evals, or prepare datasets, and access its library and tools from another computer.

Accessing servers from outside of your LAN uses Tailscale. This is a free service that you can install on both machines. Once they are logged into the same tailnet, the Stimma installs should see each other.

Read the [Remote Access documentation](https://docs.stimma.ai/remote-access/) for setup and details.

## Headless Stimma Server for Linux

Stimma Server can now run in Docker on Linux without a desktop environment. Both **amd64 and arm64** are supported, making it suitable for an always-on server or homelab. Connect from the Stimma desktop app to use the server's library, tools, and agent workflows.

Sign in by approving a short activation code in a browser, then select the server in the desktop app. Existing media folders can be mounted read-only as Sources. The server can update itself on a schedule, waiting for active work to finish.

## Use Your ChatGPT or Codex Subscription

ChatGPT is now available as an AI-service connection alongside API-key providers. Sign in with your OpenAI account to use the models included with your ChatGPT or Codex subscription instead of supplying an API key and paying separately per token.

Stimma discovers the models and reasoning levels available through your account, shows plan usage windows when provided, and explains when a request has reached a subscription limit.

## Stimma Is Now Built on Electron

This release moves the Stimma desktop application to Electron, giving it a consistent rendering engine across Windows, macOS, and Linux.

The change brings several immediate improvements:

- The interface renders more consistently across all three platforms.
- Application and visual-editor performance improve, particularly on macOS and Linux.
- Wacom tablets now work consistently across all platforms.
- File dragging now works correctly under Linux Wayland.

Startup is also substantially faster, especially on Windows. Existing profiles and settings migrate automatically.

## Linux Support

Linux support has received particular attention, with extensive testing on Omarchy and Ubuntu. Alongside the performance and input improvements above, font rendering is improved and installation is less dependent on libraries supplied by your distribution.

## Current Local AI Models

This version of Stimma includes minor fixes that enable the use of several of the most important new local LLMs including:

- **Qwen3.5-27B**
- **Qwen 3.8 Flash Next**
- **GLM 5.3 Flash**

**GLM 5.3 Flash**, **Claude Fable 5.1**, and **GPT 6 Astra** are also available through Stimma's hosted AI service.

## ComfyUI-Stimma

ComfyUI integration has been smoothed out based on feedback from the last release:

- The Stimma manager reconnects automatically after ComfyUI restarts, so its status and controls return without reopening the manager.
- A failed download, installation, or other operation no longer makes the entire ComfyUI provider appear unhealthy.
- Fixed valid LTX-2.5 Gemma encoder downloads being rejected.

Additionally there is a new Krea 2 RAW->Turbo workflow, reflecting how many people prefer to run Krea.

## Generation and Media

- LoRA weights can now range from `-10` to `10`, including in connected ComfyUI workflows, enabling the use of slider LoRAs.
- Send To and Hop To menus only show tools that are currently available.
- Broken or incomplete FFmpeg installations are detected properly, with guidance for repairing the installation.
- Videos fall back to ordinary playback when seamless looping cannot be initialized.
- The code tool can create, read, and inspect ZIP archives.
- Temporary copies created for dragging media into other applications are cleaned up automatically and removed when the original media is permanently deleted.

## Fixes and Performance

- Marker toggles and tag edits now update immediately in slideshows, including those opened from chat.
- Fixed AI reasoning text appearing in enhanced prompts.
- Fixed the chat Stop button becoming ineffective after a tool permission decision.
- Saving agent permissions or memory no longer resets your selected AI models.
- Background progress no longer counts disabled indexing or analysis tasks as unfinished work.
- Tool-provider authentication tokens are now saved correctly and reused when testing connections.
- Fixed slow AI requests failing prematurely while waiting for a response.
- Checking for updates now also checks the connected Stimma Server; opening server setup refreshes its update status.
- Fixed local reasoning-effort detection for connected AI services.
- Space-to-dictate works with keyboards forwarded through remote-desktop software.
- Slideshows preload neighboring images for smoother navigation.
